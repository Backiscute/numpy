# Exercises

A collection of exercises and small projects, mostly in signal processing, data analysis and scientific computing, realised with **NumPy**, **pandas** and **Matplotlib**.

## Contents

Each exercise lives in its own folder and usually contains:

- the Python script(s) solving the exercise
- a `README.md` explaining the problem and the approach
- an `images/` folder with the resulting plots

## Installation

Python 3.9 or newer is recommended. Install the dependencies with:

```bash
pip install -r requirements.txt
```

Then run any exercise from its folder, for example:

```bash
python exercise.py
```

## Note on languages

Some exercises were originally written in another language (mostly French) and have been translated into English: comments, variable names, plot labels and documentation. When this is the case, the original file is kept next to the translated one, usually named `original.py`, so the two versions can be compared.

The translations aim to keep the logic identical to the original. Only the language changes, apart from small fixes noted in the exercise's own README.

## Libraries used

| Library | Purpose |
|---------|---------|
| [NumPy](https://numpy.org/) | Numerical computation and arrays |
| [pandas](https://pandas.pydata.org/) | Data loading and manipulation |
| [Matplotlib](https://matplotlib.org/) | Plotting |
